# E0001 — Preliminary controlled denoising comparison

Date: 2026-11-11. Blender 5.0.1, factory startup scene, 48 × 40, Cycles CPU.

Inputs: exactly one 16-samples-per-pixel render (seed 539), evaluated through a compositor with RAW, Standard, High, Super. Independent reference: raw 256 spp (seed 8819). This reference is **not proven converged**. OIDN is configured through Blender's native Denoise node (Quality=High, Prefilter=Accurate). The same raw Cycles data feed all branches.

Source: GitHub Actions Blender smoke, run 43049506241 and ablation run 43049857147 (artifacts retained temporarily).

## What we learned
- The raw lighting-pass reconstruction is essentially exact for this tiny factory scene. The large High/Super error is not explained by basic missing light contributions.
- Removing the final denoiser has negligible impact on the issue. The large residual arises before final denoising, either in per-component denoising or how the auxiliary information conditions it.
- Higher denoiser count alone is not proof of a better image. High and Super currently **lose** substantial accuracy here.
- No general claim about SID original, real interiors, glossy regions or reference convergence is possible based on this miniature scene.

## Next isolations
1. Remove normal/albedo guidance from subpass denoisers, retaining their same raw light inputs (same source render).
2. Compare each denoised family against its corresponding raw family, with per-pass residual maps.
3. Test robust scene geometries: indirect architectural interior, reflective/transmissive surfaces, small light sources.
4. Repeat at 64/128/256 spp with multiple independent seeds and a convergence-checked reference.

Never present this experiment as a quantitative comparison to commercial SID 5.3: only the historical public design was used.
