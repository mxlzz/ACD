# E0006 — Emission-preserving denoising ablation

Date: 2026-11-11; Classroom CC0 single-input comparative test. Experimental finding,
not proof of general superiority over OIDN or SID.

Blender 5.0.1, 384x216, Cycles CPU. Same 32 spp raw input (seed 539)
and 256 spp nonconverged raw reference (nominal seed 8819; seed independence NOT verified).
Run: https://github.com/mxlzz/ACD/actions/runs/43059325530

## Algorithm

    C_no_emission = C_raw - emission_raw
    C_candidate = OIDN(C_no_emission, normal, albedo) + emission_raw

We change the input to OIDN while retaining the raw emission AOV as a
separate additive contribution. All arithmetic remains in linear HDR.

## Results versus finite reference (seed independence unverified)

| Region | Standard RGB RMSE | Emission-protected RGB RMSE |
| --- | ---: | ---: |
| Whole image | 0.0439607 | **0.0436443** |
| Emission dominated (1.42% pixels) | 0.0601497 | **0.0343227** |

Global RMSE reduction: approximately 0.72%.
Emission-region RMSE reduction: approximately 42.94%.
Whole-image MAE also improved from ~0.02113 to ~0.02090.

Emission-mask RMSE of the original raw image was 0.0356021,
slightly higher than the protected result in this one sample.
The emission region is small and defined by a noisy AOV, not
object/material semantic segmentation.

## Critical limitations

Only one seed, one scene, one 256 spp reference; no confirmed convergence.
The subtraction before OIDN changes its input distribution; the same
algorithm could be worse with indirect emissive bounces or different lights.
E0007 instead identified that changing Cycles seed (and sample_offset) in
this official Classroom scene failed to produce meaningful noisy-image
variation, even in independent Blender processes. See E0007.md.
The planned four-seed interpretation is therefore on hold pending
a physically comparable, demonstrably varied sampling procedure.
