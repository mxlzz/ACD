# E0008 — Controlled emission-preservation ablation across three verified noisy inputs

Date: 2026-11-11. EXPERIMENTAL — not a release criterion or commercial SID equivalence.

## Setup and provenance

- Blender 5.0.1, Cycles CPU, procedural architectural mini-interior with
  directly visible emissive lighting strips and reflected/indirect lighting.
- Resolution 128x96; 24 samples/pixel for each noisy input.
- Input seeds 539, 911 and 1337 were **numerically verified to produce
  distinguishable raw images**; all input pairs pass the diversity heuristic.
  This checks meaningful image variation, not a statistical independence proof.
- Two separate unfiltered reference images: 1024 spp, nominal seeds 8819 and 8922.
  Reference-to-reference RGB RMSE was ~0.0527. These references have
  significant residual disagreement and are NOT converged ground truth.
- Same noisy render for all denoiser methods within a particular input seed.
- Methods: Raw, Standard, High, Super, and Standard with raw emission preserved:
  D = OIDN(Raw - Emission_raw; Normal, Albedo) + Emission_raw.
- Emitter region: fixed mask computed from the baseline raw multilayer EXR.
  Dominant-emission threshold >=35% of available absolute AOV contribution,
  minimum linear signal 0.01. Mask covers 66 pixels, ~0.537% of image.
  It is a radiance-attribution region, not an object/material ID mask.

## Global mean errors across three noisy input seeds

| Method | Mean linear RGB RMSE | Mean linear RGB MAE |
| --- | ---: | ---: |
| Raw | 0.254602 | 0.143809 |
| Standard | **0.091558** | 0.040507 |
| Standard, emission preserved | 0.091715 | 0.040806 |
| High | 0.099901 | 0.042642 |
| Super | 0.097350 | **0.039185** |

Preserving emission worsened the overall mean RMSE by about 0.17% against
Standard in this test; MAE also worsened.

## Fixed emission region — per-seed RGB errors

| Input seed | Standard RMSE | Emission-preserved RMSE | Standard MAE | Preserved MAE |
| --- | ---: | ---: | ---: | ---: |
| 539 | 0.306160 | **0.280591** | **0.193642** | 0.214905 |
| 911 | 0.270143 | **0.267336** | **0.184599** | 0.205008 |
| 1337 | **0.251155** | 0.267367 | **0.179315** | 0.200596 |
| Arithmetic mean | 0.275820 | **0.271765** | **0.185852** | 0.206836 |

Emission-preserving variant decreases emission-region mean RMSE by ~1.47%
and improves 2 of 3 input seeds; it increases mean MAE by ~11.29%
and is worse in MAE on all 3 seeds. This is a mixed result, not a
broad improvement. A one-number RMSE-only result would conceal that tradeoff.

## Conclusion and next gate
Do **not** enable emission preservation by default. It changes the image
in ways that reduce the most extreme error in some directly emissive
pixels while increasing average pixel error. The sample region is tiny,
references are finite and the result is limited to one artificial scene.

Next: verify corrected aggregate-regions CLI against the archived run,
repeat with broader emission areas/materials and converged references,
then investigate spatial blending with held-out scenes if warranted.
