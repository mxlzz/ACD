# E0024 — Diagnóstico de la cola de error HDR del exterior nocturno

**Propuesto, pendiente de ejecución en este commit.** Fuente: E0023, [Blender5 original run #43291659387](https://github.com/mxlzz/ACD/actions/runs/43291659387), 24 spp x3 semillas, refs 512 spp x2. No se volverá a renderizar ni se modificará el denoiser.

## Hipótesis

El RMSE global de OIDN parece empeorar en el exterior respecto del Raw aunque mejora MAE y error de bordes; el peor 1 % de píxeles concentra 92 % del SSE de OIDN contra 83 % en Raw (E0023). **No sabemos** qué proporción se explica por regiones de *referencia* muy luminosas frente a selección posterior del error raw. Un mismo ROI fijado para todos los candidatos permite desglosar RMSE/SSE dentro y fuera sin alterar los datos.

Se calculan dos máscaras disjuntas por definición de procedimiento, no entre sí: (a) 1 % de píxeles de máxima luminancia **de referencia**, (b) 1 % de píxeles con mayor error del **raw** respecto de la misma referencia. Ambas son idénticas entre todos los métodos. La máscara (b) tiene sesgo de selección favorable al raw y es **solo diagnóstico**, nunca debe usarse para entrenar/puntuar variantes de forma autónoma. Se reportan RMSE/MAE fuera de las regiones junto a fracción SSE dentro para cada método y dos referencias y tres semillas.

**Control:** [`tests/test_hdr_tail.py`](../../tests/test_hdr_tail.py) verifica caso identidad, outliers, invariancia ante candidatos, gradiente con tie selection y SSE/total. Interpretación si el RMSE global es dominado por highlights, sin atribuir causalidad a emisión AOV sin evaluar contribuciones.
