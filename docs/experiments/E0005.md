# E0005 — Official Blender Classroom public-scene baseline

Date: 2026-11-11. EXPLORATORY, not a calibrated perceptual benchmark.

## Reproducibility
- Classroom by Christophe Seux, CC0, official Blender demo scene.
- Source: https://download.blender.org/demo/test/classroom.zip
- Blender 5.0.1, Cycles CPU, scene _mainScene, layer interior, frame 1.
- .blend SHA256: 5c526ea3f280566e80253673c9955640527cd0f247ea41b1742620b5bc39f7a4
- 384x216, one noisy 32 spp input seed 539.
- One independent raw reference at 256 spp seed 8819, NOT convergence-tested.
- All methods process the exact same noisy render.
- CI evidence: https://github.com/mxlzz/ACD/actions/runs/43058679034
- Artifacts: HDR EXRs, metadata, multilayer EXR, JSON and error maps.

## Global RGB errors versus independent 256-spp reference

| Method | RMSE | MAE | log1p luminance RMSE |
| --- | ---: | ---: | ---: |
| Raw | 0.072410 | 0.041392 | 0.047115 |
| Standard | **0.043961** | **0.021132** | **0.025031** |
| High | 0.044847 | 0.021463 | 0.025441 |
| Super | 0.052703 | 0.023450 | 0.028579 |

Standard is best on these global metrics in this low-spp pilot.
Unfiltered AOV recomposition vs raw beauty RMSE: 3.553e-8.

## Region errors (relative AOV contribution dominance)

AOV radiance contribution dominance is NOT object/material segmentation.

| Dominant contribution | Coverage | Raw RMSE | Standard | High | Super |
| --- | ---: | ---: | ---: | ---: | ---: |
| Diffuse | 91.7% | 0.073398 | **0.043682** | 0.043987 | 0.049108 |
| Glossy | 10.0% | 0.062488 | **0.039014** | 0.043873 | 0.072933 |
| Transmission | 0.4% | 0.071567 | **0.026350** | 0.032137 | 0.030008 |
| Emission | 1.4% | **0.035607** | 0.060156 | 0.067826 | 0.067256 |

Filtering increases error over raw in the small emission-dominated region.
This motivates an emission-protection ablation E0006, not a global claim.

## Limitations
One noisy seed, one finite-spp nonconverged reference, small image. Tiny
emission/transmission subsets may be unstable. No measured equivalence
to the current commercial SID 5.3 distribution or perceptual superiority.
