# E0004 — Four independent input seeds, same architectural interior

Date: 2026-11-11. Objective: test whether one favorable Super result generalizes
to multiple independent noisy render seeds while **holding the scene, resolution,
sample count, compositor and both reference images constant**.

## Reproducibility

- Blender 5.0.1 / Cycles CPU.
- Procedural mini interior: 96x80, input 32 spp.
- Input random seeds: 539, 911, 1337, 2026.
- Same two independent unfiltered 4096 spp references for every input seed:
  seeds 8819 and 8922.
- Reference-to-reference RGB RMSE: 0.039410. Reference convergence not established.
- Shared same-noisy-render processing for each individual seed.
- Run https://github.com/mxlzz/ACD/actions/runs/43052249917
- GitHub Actions artifact includes per-seed EXRs, metric JSON and aggregate JSON.

## Arithmetic means over four noisy seeds (first reference)

| Method | Linear RGB RMSE | Linear RGB MAE | log1p luminance RMSE | Pixel RMSE p95 |
| --- | ---: | ---: | ---: | ---: |
| Raw | 0.190894 | 0.103004 | 0.079589 | 0.372906 |
| Standard | **0.078680** | 0.033328 | 0.025168 | 0.114824 |
| High | 0.082621 | 0.035353 | 0.026541 | 0.122558 |
| Super | 0.080243 | **0.030957** | 0.023619 | **0.105689** |
| High without Normal/Albedo | 0.076094 | 0.034954 | 0.026358 | 0.124509 |
| Super without Normal/Albedo | 0.077236 | 0.031102 | **0.023445** | 0.105891 |

**Important:** The bold Standard value is the best among the three main
user-facing configurations (Standard, High, Super). The globally lowest mean
RMSE in the whole experiment is High without guides (0.076094), an ablation.
Super's advantage in E0003 was therefore NOT consistent across all four input
seeds in global RGB RMSE. Nonetheless, Super gives smaller MAE and error
p95 on average than Standard and High, suggesting different regional bias /
outlier tradeoffs.

## RMSE winner by input seed (all ablations included)

- Standard: 2 seeds.
- High without Normal/Albedo: 1 seed.
- Super without Normal/Albedo: 1 seed.
- Regular High or Super: no outright RMSE wins in this configuration.

These four observations are far too few for confidence intervals claiming
superiority. All share a noisy, finite-spp reference; they are NOT four
independent scenes nor four ground truths.

## Conclusions

1. Pass recomposition itself remains numerically accurate, based on E0001–E0003.
2. Per-family/per-component filtering has **scene-dependent and noise-seed-dependent**
   strengths. No fixed mode is universally best even for this miniature scene.
3. Using Normal and Albedo without distinguishing what the denoised signal
   represents can sometimes *hurt* (ablation performance), but removing both
   changes different error objectives in conflicting ways.
4. ACD's next research hypothesis should be local/pass-aware selection and
   blending **validated against held-out scenes/seeds**, not another global
   chain of OIDN nodes with unmeasured sharpness.
5. A visually superior renderer needs larger scenes and perceptual assessment.
   Neither RGB RMSE nor this one experimental scene proves SID equivalence.
