# E0002 — Architectural mini-interior denoising experiment

Date: 2026-11-11. Exploratory, NOT proof of overall superiority or equivalence to SID 5.3.

## Reproducible setup
- Blender 5.0.1, Cycles CPU, procedural room: diffuse, brushed metal, transmissive glass.
- Same noisy input for all methods: 48x40 pixels, 16 spp, seed 539.
- Two independent *unfiltered* reference renders: 4096 spp each, seeds 8819 and 8922.
- CI run: https://github.com/mxlzz/ACD/actions/runs/43051041214
- Images and metrics exported in GitHub Actions artifacts.
- Reference-to-reference RMSE is 0.041418 — convergence is NOT established.

## Metrics against first 4096 spp reference

| Method | Linear RGB RMSE | Linear RGB MAE | log1p(luminance) RMSE |
| --- | ---: | ---: | ---: |
| Raw | 0.302980 | 0.152830 | 0.116799 |
| Standard | 0.154318 | 0.062116 | 0.046859 |
| High | **0.150261** | 0.064418 | 0.048939 |
| Super | 0.158825 | **0.060652** | **0.045039** |

The log-luminance column is an *offline* exploratory calculation over linear EXR using luminance coefficients (0.2126, 0.7152, 0.0722) and log1p(max(Y,0)); not HDR-FLIP. The laboratory gained corresponding automated diagnostics in a later commit.

High lowers global linear RMSE vs Standard by approximately 2.63% and ranks first against both reference seeds. However, **the ranking changes by metric**: Standard is better than High in MAE and log-luminance error; Super is best in those last two metrics. Global RMSE alone would hide this.

## Same-input ablations

| Method | Linear RMSE |
| --- | ---: |
| High without final OIDN | 0.150739 |
| Super without final OIDN | 0.160639 |
| High without normal/albedo guides | 0.160892 |
| Super without normal/albedo guides | 0.203282 |

Guidance appears beneficial in this interior, unlike the factory cube E0001. Raw Cycles vs unfiltered node-based reconstruction RMSE: 1.62e-7. Final denoiser changes RMSE only modestly.

## Limitations
- Low resolution (48x40): thin details and high-frequency textures cannot be evaluated reliably.
- Only one noisy input seed and one scene.
- Two high-spp references do not fully agree.
- No validated commercial SID 5.3 quality comparison; this is a SID-inspired method only.
- No perceptual calibrated HDR-FLIP scores yet.
