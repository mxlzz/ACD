# E0003 — Increased-resolution architectural mini-interior

Date: 2026-11-11. Preliminary experimental comparison, NOT a release-quality claim.

## Controlled setup
- Official Blender 5.0.1, Cycles CPU, procedural interior with indirect light, glass and metallic surfaces.
- Image size **96 x 80**; **32 spp** noisy input, seed 539.
- Each method (Raw, Standard, High, Super, ablations) processes the **exact same** noisy RenderLayer data in a single compositor evaluation.
- Two independent references: unfiltered **4096 spp**, seeds 8819 and 8922.
- GitHub Actions run: https://github.com/mxlzz/ACD/actions/runs/43051674524
- CI artifacts include EXRs, exact metadata and numerical metrics.
- The two reference images disagree: linear RGB RMSE **0.039410** and log1p luminance RMSE **0.015114**. This prevents assuming a converged ground truth.

## Metrics (first reference)

| Method | Linear RGB RMSE | MAE | log1p luminance RMSE | p95 per-pixel RGB RMSE |
| --- | ---: | ---: | ---: | ---: |
| Raw, 32 spp | 0.193763 | 0.105157 | 0.080730 | 0.379538 |
| Standard | 0.089322 | 0.034623 | 0.025389 | 0.113141 |
| High | 0.090164 | 0.036547 | 0.026735 | 0.122787 |
| Super | **0.085272** | **0.031372** | **0.023295** | **0.104140** |
| Super without Normal/Albedo guidance | 0.081339 | 0.031642 | 0.023616 | 0.105261 |

At 96x80, Super improves vs Standard on all four metrics reported for the same reference. In particular, Super's linear RMSE reduction vs Standard is about 4.5%, and MAE reduction about 9.4%. Unguided Super achieves the lowest global linear RMSE but is slightly worse than guided Super in MAE and log-luminance error.

The second independently seeded reference preserves the **relative ordering** of Super and Standard by global linear RMSE, though unguided Super ranks ahead of guided Super. This is still a *single noisy render seed* in a small scene.

## Controlled diagnostics
- Raw compositor recomposition vs Raw Combined: linear RGB RMSE ~2.76e-7, negligible relative to image noise.
- Disabling the final OIDN slightly worsens Super: RMSE 0.085716 vs 0.085272.
- The different E0002 48x40 scene ranked High over Standard over Super by linear RMSE. Ranking **changes with resolution/sample regime**.
- Metrics measure radiometric differences to imperfect high-spp references. The log-luminance transform is an exploratory diagnostic, not a calibrated HDR-FLIP/LPIPS perceptual score.

## Conclusions
1. Compositional Super can improve results beyond a single native OIDN pass in a controlled architectural mini-interior (positive evidence in this experiment).
2. The current evidence is insufficient to claim reliable superiority across practical scenes. We need more input seeds, larger resolutions, reflective/glass-specific tests, texture detail and temporal consistency.
3. Neither a larger number of OIDN passes nor a globally lower RMSE alone guarantees better perceptual fidelity.
4. High and Super implementation are independent *SID-inspired* prototypes. They have not been verified equivalent to the current commercial SID code.

## Next
Build multiple input-seed distributions, broaden the scene set, measure localized reflection/transmission errors, and add HDR perceptual checks before deciding how to adaptively combine denoisers. Keep the stable addon isolated until these gates pass.
